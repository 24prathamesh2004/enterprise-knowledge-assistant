# IT Security Policy

Policy owner: IT Security (Sam Okoro, sam.okoro@northwind.example)
Effective date: 2026-03-01 | Version 5.2

## Purpose and Scope

This policy defines the minimum security controls that protect Northwind Technologies systems, data, and users. It applies to all employees, contractors, and any device that connects to Northwind networks or services.

## Password Requirements

All account passwords must:

- Be at least **14 characters** long.
- Include a mix of uppercase, lowercase, numbers, and symbols.
- Be rotated every **90 days**.
- Not reuse any of the previous 10 passwords.

Passwords must never be shared, written down, or stored in plaintext. Northwind provides an approved password manager for all staff.

## Multi-Factor Authentication

**Multi-factor authentication (MFA) is mandatory** for all Northwind systems, including email, VPN, code repositories, and cloud consoles. Hardware security keys or an approved authenticator app are required; SMS-based codes are permitted only as a temporary fallback. Accounts without MFA enabled will be locked automatically after 7 days.

## Device Security

- Company devices must run full-disk encryption.
- Screens must lock automatically after **10 minutes of inactivity**.
- Operating systems and security patches must be applied within **14 days** of release.
- Antivirus and endpoint monitoring agents must remain active at all times.

Personal (BYOD) devices may access only email and calendar, and only through the managed mobile app with a device passcode enabled.

## Access Control

Access is granted on a least-privilege basis. Access reviews are conducted **quarterly** by system owners. Privileged (admin) access requires manager and IT Security approval and is reviewed monthly. All access is revoked within **24 hours** of an employee's departure.

## Incident Reporting

Any suspected security incident — including phishing, lost devices, or unauthorized access — must be reported to IT Security **within 1 hour** of discovery at security@northwind.example or via the 24/7 incident hotline. Do not attempt to investigate or remediate an incident independently.

## Data Classification

Northwind data is classified as Public, Internal, Confidential, or Restricted. Confidential and Restricted data must be encrypted in transit and at rest and may only be accessed on company-issued devices. Refer to the Data Privacy Policy for handling of personal data.

## Email and Phishing

Employees must not click links or open attachments from unverified senders. Suspected phishing emails should be reported using the "Report Phish" button. Northwind runs simulated phishing tests quarterly; repeated failures trigger mandatory retraining.

## Software and Downloads

Only software from the approved catalog may be installed. Requests for new software go through IT via the Service Portal. Unauthorized software may be removed without notice.

## Enforcement

Violations may result in access suspension and disciplinary action up to termination. Questions should be directed to IT Security at security@northwind.example.
